# Wanderly — Trips Worth Remembering

Live demo site: a travel agency with a working trip builder.

**What actually works (in your browser, no server needed):**
- Destination search filter (beach / mountain / city / name)
- Click a destination card to select it, or use the dropdown
- Trip builder: days × travelers → live price estimate
- Booking form that confirms with a trip reference

**Honest limits:** static front-end. No reservation is made and no payment
is taken. Connect a booking system to take real reservations.
